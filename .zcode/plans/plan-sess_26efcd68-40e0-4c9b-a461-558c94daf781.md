## Fix: "Invalid origin" 403 on Vercel Login

### Root Cause
`BETTER_AUTH_URL=http://localhost:3000` is set in Vercel. `env.ts` uses `process.env.BETTER_AUTH_URL || ...` which short-circuits on this truthy value, so `VERCEL_URL` fallback never runs. Browser sends `Origin: https://tapshop-wv29.vercel.app` but `trustedOrigins` is `["http://localhost:3000"]` → 403.

### Step 1 — Code fix: `src/lib/config/env.ts` (lines 29-31)
Make `betterAuthUrl` production-safe — ignore a `localhost` value in production and fall back to `VERCEL_URL`:

```ts
export const betterAuthUrl = isProd
  ? (process.env.BETTER_AUTH_URL && !process.env.BETTER_AUTH_URL.includes("localhost")
      ? process.env.BETTER_AUTH_URL
      : process.env.VERCEL_URL
        ? `https://${process.env.VERCEL_URL}`
        : undefined)
  : process.env.BETTER_AUTH_URL || undefined;
```

### Step 2 — Vercel env cleanup
Go to **Vercel Dashboard → tapshop → Settings → Environment Variables** and **delete** the `BETTER_AUTH_URL` variable (or update it to `https://tapshop-wv29.vercel.app`).
