## Fix: Vercel Login Not Working

### Root Cause
`BETTER_AUTH_URL` is not set to the production URL on Vercel, causing Better Auth to reject all login requests (no trusted origin). Additionally, the production database may be missing auth tables and demo accounts.

### Code Change (1 file)

**`src/lib/config/env.ts`** — Auto-detect production URL from Vercel's `VERCEL_URL` env var:

```ts
export const betterAuthUrl =
  process.env.BETTER_AUTH_URL ||
  (process.env.VERCEL_URL ? `https://${process.env.VERCEL_URL}` : undefined);
```

This makes `BETTER_AUTH_URL` optional on Vercel (auto-detected), while keeping local dev unchanged.

### Post-Change Steps

1. **Run migrations against production DB:**
   `DATABASE_URL="<neon-url>" pnpm db:push`

2. **Seed demo accounts into production DB:**
   `DATABASE_URL="<neon-url>" pnpm db:seed`

3. **Verify Vercel env vars** are set: `DATABASE_URL`, `BETTER_AUTH_SECRET`, `ADMIN_EMAILS`

4. **Redeploy** on Vercel

After these steps, login with `demo@tapshop.com` / `password123` will work on Vercel.
