## Stats Dashboard Implementation Plan

A mobile-first Stats screen for TapShop with a shared 4-tab bottom nav, **real aggregated data** from `bill_entries`, a **recharts** weekly bar chart, and the existing indigo/lavender design tokens. Font is **already Inter** (`src/app/layout.tsx`) — no font change needed.

---

### 1. Dependencies
- `pnpm add recharts` (recharts 3.x, supports React 19). Used only inside a `"use client"` chart component.

### 2. Design tokens (`src/app/globals.css`) — small additions
- Add `--bottom-nav-h: 4.5rem;` to `:root` and `.dark` (shared nav-height constant).
- Add `--stats-bg` (soft lavender: light `oklch(0.982 0.012 290)`, dark variant) + map `--color-stats-bg` in `@theme inline` so `bg-stats-bg` utility works and respects dark mode.

### 3. Stats data service — NEW `src/lib/services/stats.ts`
Follows the existing `src/lib/services/billing.ts` patterns (uses `db`, `num()`, `sql`, `billEntries`, `items`). Exports a single `getStats(userId)` returning a serializable object:
- **todaySpend** — `sum(subtotal) where billDate = CURRENT_DATE`
- **yesterdaySpend** — same, `CURRENT_DATE - INTERVAL '1 day'` (for the "↘ 12% from yesterday" trend)
- **weekSpend** — `sum(subtotal) where billDate >= date_trunc('week', CURRENT_DATE)::date`
- **monthSpend** — `sum(subtotal) where billDate >= date_trunc('month', CURRENT_DATE)::date`
- **itemsTapped** — `sum(quantity)` over last 30 days (the "42 taps" figure)
- **mostUsed** — item with max `sum(quantity)` over last 30 days → `{ name, icon }` (or `null`)
- **weekly** — current week Mon–Sun daily `sum(subtotal)`, mapped to `{ label: "Mon".."Sun", value }` (7-element skeleton filled from the grouped query)

All amounts formatted client-side via existing `formatCurrency()` (produces `৳240`, `৳1,120`, etc.).

### 4. Stats route — NEW `src/app/(user)/stats/page.tsx`
Server component: `requireUser()` → `Promise.all([getStats(session.user.id)])` → renders `<StatsScreen stats={...} />`. Mirrors the existing `home/page.tsx` pattern.

### 5. Stats screen — NEW `src/components/stats/stats-screen.tsx` (`"use client"`)
Root: `mx-auto flex min-h-[100dvh] w-full max-w-md flex-col bg-stats-bg` with bottom padding `pb-[calc(var(--bottom-nav-h)+env(safe-area-inset-bottom)+1.5rem)]`. Sections (matching the reference, top→bottom):
- **Header**: circular indigo 🧾 brand mark (left), bold indigo **"TapShop"** (center), indigo `Bell` (right). Transparent over the lavender bg, lightweight.
- **Intro**: large bold **"Your Stats"** + muted subtitle "Track your spending habits and keep your finances in check."
- **Today's Spend card**: `bg-primary` (indigo), large rounded (`rounded-3xl`), white text. Circular `Wallet` icon container (`bg-white/15`), label **"TODAY'S SPEND"**, big `formatCurrency(todaySpend)`, trend line "↘/↗ N% from yesterday" (computed from today vs yesterday; handles yesterday=0 gracefully) in `text-white/80`.
- **2-col grid** (soft cards): **This Week** (`BarChart3`, `text-info`/`bg-info/10`, **৳**`weekSpend`) and **This Month** (`CalendarDays`, `text-success`/`bg-success/10`, `monthSpend`).
- **2-col grid** (white cards): **Items** (`ShoppingBag`, `text-destructive`/`bg-destructive/10`, big `itemsTapped`, "taps" subtext) and **Most Used** (`Coffee`, `text-warning`/`bg-warning/15`, label, pill with `mostUsed.icon` + name; fallback "Nothing yet").
- **Weekly Activity card** (white, rounded): bold **"Weekly Activity"** + `MoreHorizontal` overflow; `<WeeklyActivityChart data={weekly} />` below.

Icons all from `lucide-react` (Bell, Wallet, BarChart3, CalendarDays, ShoppingBag, Coffee, MoreHorizontal). Uses existing tokens (`primary`, `info`, `success`, `destructive`, `warning`, `muted-foreground`, `card`).

### 6. Weekly chart — NEW `src/components/stats/weekly-activity-chart.tsx` (`"use client"`)
- recharts `ResponsiveContainer` (height ~200px) + `BarChart`.
- Rounded indigo bars: `<Bar dataKey="value" radius={[10,10,0,0]} fill="var(--primary)" maxBarSize={26} />`.
- `XAxis dataKey="label"` (Mon–Sun), no axis/tick lines, muted labels; `YAxis hide`; no `CartesianGrid`; minimal styled `Tooltip`.
- `mounted` guard (`useEffect`) + a `Skeleton` placeholder of the same height before mount to avoid SSR hydration/layout issues.

### 7. Shared bottom nav — NEW `src/app/(user)/layout.tsx`
Server layout rendering `{children}` + `<BottomNav />`. Wraps existing `home`, `profile`, and new `stats`, `activity` routes. (Auth route group is separate and unaffected.)

### 8. Bottom nav component — NEW `src/components/bottom-nav.tsx` (`"use client"`)
- `fixed bottom-0 inset-x-0 z-40 h-[var(--bottom-nav-h)]`, white bg, subtle top border/shadow, internal `paddingBottom: env(safe-area-inset-bottom)`, inner `max-w-md mx-auto`, 4 evenly-spaced tabs.
- Uses `usePathname()` to mark active. **Stats** active here: light-indigo circular bg behind icon (`bg-primary/10 rounded-full`), indigo icon + indigo label; others muted gray.
- Tabs: **Home** (`/home`, `Home`/`House`), **Activity** (`/activity`, `ReceiptText`), **Stats** (`/stats`, `ChartColumn`), **Profile** (`/profile`, `User`).

### 9. Activity stub — NEW `src/app/(user)/activity/page.tsx`
Minimal server page (`requireUser()` + a clean centered empty-state "Activity coming soon") reusing the page shell + bottom clearance, so the Activity tab isn't broken. (Full Activity screen is out of scope.)

### 10. Reconcile Home's sticky bar — MODIFY `src/components/billing/bill-summary.tsx`
Change the outer wrapper from `sticky bottom-0` to `sticky bottom-[calc(var(--bottom-nav-h)+env(safe-area-inset-bottom))]` (via inline style) so the bill HUD sits just above the fixed nav, and reduce its own bottom safe-area padding (the nav now owns the bottom safe area). Keeps `z-30` (< nav `z-40`) and existing `mt-auto` behavior intact.

### 11. Profile clearance — MODIFY `src/components/user/profile-view.tsx`
Add bottom padding `pb-[calc(var(--bottom-nav-h)+env(safe-area-inset-bottom)+1rem)]` to the root so the Profile card isn't hidden behind the fixed nav.
