# Plan: Clickable Dashboard Stat Cards → Drill-Down Detail Pages

## Overview

Each of the 4 dashboard stat cards (Total Users, Today's Spend, Month Revenue, Active Today) becomes clickable, navigating to a dedicated detail page that shows a breakdown list of users.

## 1. Make StatCard clickable

**Modify:** `src/components/admin/stat-card.tsx`

- Add `href?: string` prop
- When `href` is provided, render content inside a `<Link href={href}>` with `cursor-pointer` added to classes
- Keep all existing styling (variant, shadow, etc.)
- Add `transition-transform hover:scale-[1.02]` for subtle press feedback

## 2. Wire dashboard stat cards to routes

**Modify:** `src/components/admin/dashboard-screen.tsx`

- Import `Link` from `next/link` (already imported)
- Pass `href` to each `StatCard`:
  - Total Users → `href="/users"` (existing users list page)
  - Today's Spend → `href="/dashboard/today"` (new)
  - Month Revenue → `href="/dashboard/month"` (new)
  - Active Today → `href="/dashboard/active"` (new)

## 3. Update bottom nav to hide on drill-down pages

**Modify:** `src/components/admin/admin-bottom-nav.tsx`

- Extend `isDetailPage` logic to also cover `/dashboard/today`, `/dashboard/month`, `/dashboard/active`:
  ```ts
  const isDetailPage =
    (pathname.startsWith("/users/") || pathname.startsWith("/dashboard/")) &&
    pathname.split("/").length >= 3;
  ```
- This keeps the nav hidden on all drill-down pages (matching existing behavior for `/users/[id]`)

## 5. Add new service functions

**Modify:** `src/lib/services/admin.ts`

**`getTodayBreakdown()`** → `{ total: number, users: TodayUserSpend[] }`
- Query `billEntries` for today, inner join `users`, group by `userId`
- SELECT: `sum(subtotal)`, `count(*)`, `max(consumedAt)` per user
- ORDER BY amount descending

**`getMonthBreakdown()`** → `{ total: number, users: MonthUserSpend[] }`
- Query `billEntries` for this month (>= date_trunc month), inner join `users`, group by `userId`
- SELECT: `sum(subtotal)`, `count(*)` per user
- Calculate `percentage = (userTotal / grandTotal) * 100` client-side
- ORDER BY amount descending

**`getActiveTodayUsers()`** → `ActiveTodayUser[]`
- Query `billEntries` for today, inner join `users`
- Get distinct users with today's total, `max(consumedAt)`, group by `userId`
- ORDER BY today's total descending

## 6. Create 3 new screen components

### `src/components/admin/today-breakdown-screen.tsx`
- Header: "Today's Spend" title + total amount in indigo summary card
- Back button (router.back())
- List of users sorted by amount desc:
  - Each row: avatar, name, amount (formatted currency), last tap time (relative via `formatRelativeTime`), tap count badge
- Empty state when no spending today

### `src/components/admin/month-breakdown-screen.tsx`
- Header: "Month Revenue" title + total amount in indigo summary card
- Back button (router.back())
- List of users sorted by amount desc:
  - Each row: avatar, name, amount (formatted currency), percentage bar + label, tap count badge
- Empty state when no revenue this month

### `src/components/admin/active-today-screen.tsx`
- Header: "Active Today" title + count in indigo summary card
- Back button (router.back())
- List of active users:
  - Each row: avatar, name, email, green status dot, today's spend, last active time
- Empty state when no active users

All 3 components are `"use client"` with `useRouter` for the back button, following existing patterns (e.g., `user-details-screen.tsx`).

## 7. Create 3 new page routes

| Route | File | Data Source |
|-------|------|-------------|
| `/dashboard/today` | `src/app/(admin)/dashboard/today/page.tsx` | `getTodayBreakdown()` |

Each is an async server component with `export const metadata`, calls the service function, and renders the screen component.
