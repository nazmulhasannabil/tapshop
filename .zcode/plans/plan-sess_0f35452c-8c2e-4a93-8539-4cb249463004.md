# Recent Activity Screen — Implementation Plan

Build a polished, mobile-first **Recent Activity** screen at the existing `/activity` route (currently a `ComingSoon` placeholder), wired to **real data** from `bill_entries` (one card per item-per-day, ordered by last-tap time). Reuses the existing design tokens, formatters, bottom nav, and component patterns — no new deps.

## Design system in use (already defined — no new tokens)
- **Indigo** → `primary`; **Lavender** → `accent`; **Mint/Green badge** → `success`/`success-foreground`; cards → `bg-card`; bg → `background`.
- Font: **Inter** is already `--font-sans` (default).
- Reuse `formatCurrency()` (৳) and `formatRelativeTime()` ("2m ago") from `src/lib/constants.ts` — both purpose-built for this.
- Match the Home (`BillingScreen`) shell: `mx-auto flex min-h-[100dvh] w-full max-w-md flex-col`.

## 1. Data layer

### `src/types/bill.ts` — add `ActivityEntry` type
```ts
export type ActivityEntry = {
  id: string;            // bill_entries.id
  itemId: string;
  name: string;
  icon: string | null;
  quantity: number;      // cumulative taps for that item-day
  unitPrice: number;     // snapshot
  subtotal: number;
  consumedAt: string;    // ISO — first tap of the day
  updatedAt: string;     // ISO — most recent tap (drives ordering + "time ago")
};
```

### `src/lib/services/billing.ts` — add `getActivityFeed()`
Model on `getTodayBill()`/`getRecentItems()`:
```ts
export async function getActivityFeed(userId: string, limit = 30): Promise<ActivityEntry[]> {
  const rows = await db
    .select({
      id: billEntries.id, itemId: billEntries.itemId,
      name: items.name, icon: items.icon,
      quantity: billEntries.quantity,
      unitPrice: billEntries.unitPrice, subtotal: billEntries.subtotal,
      consumedAt: billEntries.consumedAt, updatedAt: billEntries.updatedAt,
    })
    .from(billEntries)
    .innerJoin(items, eq(billEntries.itemId, items.id))
    .where(eq(billEntries.userId, userId))
    .orderBy(desc(billEntries.updatedAt))
    .limit(limit);
  return rows.map((r) => ({
    id: r.id, itemId: r.itemId, name: r.name, icon: r.icon,
    quantity: r.quantity,
    unitPrice: num(r.unitPrice), subtotal: num(r.subtotal),
    consumedAt: r.consumedAt.toISOString(), updatedAt: r.updatedAt.toISOString(),
  }));
}
```
Add `ActivityEntry` to the existing type import block.

## 2. UI components (new folder `src/components/activity/`)

### `app-header.tsx` (place in `src/components/nav/` next to `bottom-nav.tsx`)
Reusable top header, mounted only on Activity (not added to the user layout, so Home/Profile/Stats are untouched):
- `sticky top-0 z-30 bg-background/95 backdrop-blur-md border-b border-border/60`, centered `max-w-md`, `h-14`.
- **Left:** circular logo — `size-9 rounded-full bg-primary/10 flex items-center justify-center` with a `Coffee` (or `ShoppingBag`) lucide icon in `text-primary`.
- **Center:** `TapShop` in `text-lg font-bold text-primary`.
- **Right:** `<Bell />` button in `text-primary`.
- `"use client"` (bell is a `<button>`); bell is a no-op stub for now (accessible, with hover).

### `activity-timeline.tsx`
Vertical timeline rendering each `ActivityEntry`:
- `relative` container with a single absolute thin line `absolute left-5 top-3 bottom-3 w-px bg-primary/20` behind the nodes (standard timeline technique — nodes punch through with solid bg).
- Each item is a `flex gap-3` row: **node gutter** (`w-10` column) + **card** (`flex-1`).
- **Nodes:** newest (`index === 0`) → `size-4 rounded-full bg-primary ring-4 ring-primary/15`; older → `size-3.5 rounded-full bg-accent ring-1 ring-primary/15`. Centered in the gutter over the line.

### `activity-card.tsx`
White rounded transaction card (per spec), `motion.div` with `whileTap={{ scale: 0.98 }}` + `role="button"` + keyboard handler calling `onSelect(entry)`:
- Container: `flex items-center gap-3 rounded-3xl bg-card p-4 shadow-sm ring-1 ring-foreground/5` (matches Home hero card).
- **Left icon:** `size-12 rounded-full bg-accent flex items-center justify-center` with `<span className="text-2xl">{icon ?? "🍽️"}</span>`.
- **Center column:** name row = name (`text-base font-semibold`) + small emoji + **green pill** `+{quantity}` (`rounded-full bg-success px-2 py-0.5 text-xs font-semibold text-success-foreground`); below it `formatRelativeTime(updatedAt)` in `text-xs text-muted-foreground`.
- **Right amount:** `ml-auto tnum text-xl font-bold text-foreground` = `formatCurrency(subtotal)`.

### `activity-detail-sheet.tsx`
Opens on card tap, using the existing `@/components/ui/sheet` primitive (consistent with `bill-sheet.tsx`/`add-item-sheet.tsx`):
- Shows large item emoji, name, quantity badge, unit price (`formatCurrency(unitPrice)`), subtotal (`formatCurrency(subtotal)`), relative + absolute timestamp, and a close affordance.

### `activity-screen.tsx` (`"use client"`) — the screen body
- Holds `selected` state for the detail sheet.
- Shell: `mx-auto flex min-h-[100dvh] w-full max-w-md flex-col` → `<AppHeader />` → `<main className="flex-1 space-y-5 px-4 pb-28 pt-5">`.

## Behavior & constraints honored
- **Bottom nav:** already exists and auto-highlights Activity on `/activity` — untouched.
- **Newest at top / grows on reload:** `orderBy(desc(updatedAt))`.
- **Scrolling:** native scroll; renders the 30 most recent item-day entries (true infinite scroll noted as a future enhancement, not built now).
- **Safe areas:** body already pads `env(safe-area-inset-top)`; bottom nav pads bottom; `pb-28` clears the nav.
- **Subtle touch feedback:** `motion` `whileTap` on cards (matches `recent-taps.tsx`/`bill-item-card.tsx`).
- **No** charts, filters, tabs, search, or sidebars — just header + intro + timeline + cards + detail sheet.
- Consistent with Home/Stats styling tokens and the `Section`/card idioms.
